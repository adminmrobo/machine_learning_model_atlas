1. 사실 · 정의 · 등급, 세 층을 나눈다

도감의 별점 하나에는 성격이 다른 세 층이 겹쳐 있습니다. 문헌이 뒷받침하는 것은 주로 첫째 층입니다.

1층 · 사실

문헌·공식 구현이 말하는 것

"이 구현은 결측을 지원한다", "선형 점수함수를 쓴다", "원논문의 특정 실험에서 잔차 연결이 최적화를 도왔다".

2층 · 운영 정의

무엇을 어떤 조건에서 재는가

'해석 쉬움'을 누가(초보 학습자), 어떤 과제에서, 어떤 모델 크기로 판단하는지 정한 규칙.

3층 · 등급

작성자의 교육용 판단

1층의 사실에 2층의 규칙을 적용해 매긴 점수. 독립 검토와 사용자 검증이 필요하다.

그래서 별점은 "논문이 인증한 5점"이 아니라 "문헌 사실을 참고해 자체 루브릭으로 매긴 교육용 등급"으로 기록합니다. 복합지표를 만들 때 개념·가중·집계·민감도를 따져야 한다는 방법론[R1]을 참고했지만, 그 기관이 이 도감의 별점을 승인했다는 뜻은 아닙니다.

2. 평가 단위 — 무엇을 평가하는지 먼저 고정한다

"선형 회귀"라는 이름만으로는 평가 대상이 정해지지 않습니다. 원변수로 쓰는지 다항항을 붙이는지에 따라 표현력이 달라지기 때문입니다. 그래서 점수를 매기기 전에 아래 항목을 적습니다.

항목기록 규칙
과제군표 회귀·분류 / 군집 / 차원 축소 / 이상 탐지 / 영상 / 시퀀스 / 생성 / 신경 모사
입력 표현원변수 선형 회귀와 다항기저 선형 회귀, 선형 SVM과 RBF 커널 SVM을 구분

과제군이 다른 모델은 한 줄로 세우지 않습니다. 군집 모델의 표현력과 분류기의 표현력은 같은 자로 잴 수 없습니다. 머신러닝 4축, 신경망 3축, 로봇 대전 RPG 수치를 평균해 총점을 만들지도 않습니다.

4. 축별 판단 기준

4-1. 표현력 — 세 구간으로 나눈다

정해 둔 입력·모델군·규모에서 표현할 수 있는 함수나 구조의 범위입니다. 학습이 잘 되는지, 정확도가 높은지, 새 데이터에서 잘 맞는지와는 다른 이야기입니다.

선형원변수에 대한 직선·평면 경계. 선형 회귀, 로지스틱 회귀, LDA, 선형 SVM
제한된 비선형곡선은 만들되 구조 제약이 강함. 얕은 트리, kNN, 나이브 베이즈 등 (조건 태그 필수)
유연한 비선형규모를 키우면 복잡한 구조를 담음. 부스팅, 커널 SVM, 다층 퍼셉트론 등

E25 · 데헷 (수줍게)솔직히… 4점과 5점을 가를 이론이나 실험은 저도 못 찾았어요. 데헷.

E07 · 설명그래서 5칸 막대는 그대로 두되 1·3·5칸만 쓰는 안이에요. 근거 없는 칸은 비워 둬요. 그러면 같은 직선을 긋는 선형 회귀(1)와 로지스틱 회귀(2)가 다른 점수를 받는 일도 없어져요.
  • 로지스틱 회귀의 S자 함수는 출력을 확률로 바꿀 뿐, 결정 경계는 그대로 직선입니다. 그래서 선형 회귀보다 표현력을 높게 주지 않습니다.
  • 범용근사 정리는 "충분히 크면 가능하다"는 존재 정리입니다. 모든 크기의 신경망에 최고점을 주는 근거가 아닙니다.
  • 표현력이 높다는 것은 실제 정확도가 높다는 결론이 아닙니다.

4-2. 해석 쉬움 — 초보자가 직접 따라갈 수 있나

초보자가 모델 구조와 개별 예측을 도구 없이 직접 따라가는 부담으로 정의합니다. 전체 계산을 추적할 수 있는지, 구성 요소에 의미가 있는지, 학습 절차가 투명한지를 나눠 봅니다[R2 §3.1–3.2, §4.1]. "선형"이라는 이름만으로 변수 수백 개짜리 모델까지 쉽다고 보지 않습니다.

등급그 사용자·과제에서의 의미
5지정한 소규모 모델의 전체 규칙·구성 요소·예측을 직접 설명할 수 있다
4핵심 구조와 예측을 대체로 직접 설명하되, 일부 변환·조건은 이해가 필요하다
3개별 예측이나 일부 구성 요소는 이해되지만 전체 구조는 부담스럽다
2원리는 설명할 수 있으나 실제 예측을 따라가려면 상당한 보조가 필요하다
1전체 규칙과 개별 계산 모두 직접 따라가기 매우 어렵다

검증되지 않은 순서형 기준입니다. 5점이 1점보다 다섯 배 쉽다는 뜻이 아닙니다. SHAP 같은 사후 설명 도구를 쓸 수 있다는 점은 별도 항목으로 적고, 직접 해석 점수를 자동으로 올리지 않습니다. 사람을 대상으로 한 실험(예측 따라 하기, 오류 찾기, 입력을 바꿨을 때 결과 예상하기)을 하지 않았으므로 지금 등급은 구조적 대리지표 평가입니다[R3 §3].

4-3. 다루기 쉬움 — 올바른 파이프라인을 만드는 부담

정해진 구현과 데이터에서 제대로 된 학습 파이프라인을 만드는 부담입니다. 정확도나 속도 자체가 아닙니다. 전처리, 민감한 설정과 실패 진단, 자원 관리, 설치와 재현성을 따로 적습니다.

4-4. 학습 안정성 — 신경망 도감 전용

수치 발산, 정해진 예산 안에서 수렴하지 못함, 초기값에 따른 성능 차이, 설정값 민감도는 서로 다른 현상입니다. 실패 기준을 미리 정하고, 같은 분할·예산에서 시드를 여러 개 돌려 실패 비율과 성능·시간 분포를 따로 적어야 합니다. 실험하지 않은 항목은 "원논문 조건에서 안정화 보고" 또는 "미측정"으로 씁니다. 딥러닝 강화학습의 재현성 논의[R4]는 조건과 반복을 기록해야 하는 이유의 참고일 뿐, 모든 신경망의 안정성 점수를 검증한 자료가 아닙니다. 순환 신경망의 '안정적인 동역학'과 학습이 '안정적으로 수렴함'도 서로 다른 개념이라 섞지 않습니다.
