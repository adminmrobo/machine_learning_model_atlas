# 머신러닝 모델 도감 · 엣센스

고전 머신러닝 모델 27가지를 같은 모눈 위에 하나씩 그리고, 각각이 무엇을 긋는 모델인지와 강점·약점을 쉬운 말로 푼 한 장짜리 도감입니다. [신경망 구조 도감](https://adminmrobo.github.io/neural_network_atlas/)의 자매편입니다.

사이트: https://adminmrobo.github.io/machine_learning_model_atlas/

- 선형 모델 5종 · 이웃·마진·확률 5종 · 나무와 숲 3종 · 부스팅 5종 · 군집 4종 · 차원 축소 3종 · 이상 탐지와 다층 퍼셉트론 2종
- 카드마다 그림, 설명, 비유, 강점·약점, "그림에 안 보이는 차이", 상대 평가(표현력·해석 쉬움·다루기 쉬움·요즘 활용도)
- 과제별 보기(회귀·분류·군집·차원 축소·이상 탐지)
- 카드마다 3D판 [머신러닝 연구소](https://adminmrobo.github.io/machine_learning_in_3d/)의 해당 층으로 가는 단추 (같은 27종을 27층 건물로 옮겨, 직접 돌려 보는 실험을 붙였습니다)

그림은 설명을 위해 만든 가상의 점 위에 그린 도식이며 실제 학습 결과가 아닙니다. 별점은 같은 조건을 가정한 상대 평가입니다.
